# VALYQON AI: Railway закрыт для регистрации — безопасный запасной путь

Проверено 27 октября 2026 года: https://status.railway.com/ подтверждает
остановку **новых** регистраций после инцидента 21 октября. Ошибка
`Error authenticating with GitHub / Sign ups are currently disabled` — это
ограничение Railway, а не ошибка GitHub или VALYQON.

## Если Railway уже использовался ранее

Входите **тем же** GitHub/email, на который первоначально был создан Railway.
Railway официально попросил существующих пользователей восстановить сессии,
проверить связанные OAuth-приложения и сменить секреты потенциально затронутых
workspace после инцидента:
https://blog.railway.com/p/security-disclosure-recommendation-recover-account-access

Не создавайте новый Railway аккаунт путём смены email или GitHub-личности:
регистрация новых аккаунтов сейчас запрещена. Не передавайте авторизационные
токены, секреты из .env или приватные SSH-ключи ассистентам/в чаты.

## Если Railway-аккаунта ещё не было

В качестве **временного демонстрационного хостинга без живых клиентов**
можно вручную выбрать Render. В этой ветке добавлен `render.yaml` на
основе уже подготовленного `app.public_pilot`. Путь для выбора проекта:

https://render.com/deploy?repo=https://github.com/Ramzes2023/TenderLens-AI/tree/feat/public-pilot-render-fallback-20261027

После просмотра конфигурации нужно лично выбрать/подтвердить создание
Render web service. Код и GitHub Actions **сами ничего не развёртывают**.

1. На Render войдите через собственный GitHub.
2. Проверьте перед созданием: ровно **один** `web` service,
   `runtime: docker`, `plan: free`,
   `dockerCommand: python -m app.public_pilot`, `autoDeployTrigger: off`.
   Никаких Worker, PostgreSQL, Telegram, SMTP и платёжных сервисов.
3. Если Render предлагает платный план, дополнительный сервис, домен или
   дополнительный платёж — **не подтверждайте** без отдельного решения.
4. После запуска проверьте выданный Render URL (не угадывайте его):
   `/`, `/health`, существующие маркетинговые CSS/JS и ограничения
   регистрации. HTTP 200 у `/health` сам по себе не подтверждает, что
   лендинг выглядит корректно.
5. Сохраните фактические сетевые результаты в отчёте. До этого размещение
   имеет статус `NOT_DEPLOYED`.

## Безопасность и ограничения

- `app.public_pilot` принудительно закрывает клиентскую регистрацию,
  платежи/подписки, Telegram, email, AI и фоновый сбор источников.
  Нельзя утверждать, что публичный SaaS запущен, если опубликован лишь лендинг.
- Бесплатный Render засыпает после 15 минут без обращений, стартует с
  задержкой, использует временную файловую систему, а диски для него не
  предоставляются. **Никаких реальных аккаунтов и данных пользователей!**
- Docker-образ проекта включает серьёзные научные/AI зависимости, поэтому
  может оказаться слишком тяжёлым для бесплатного лимита RAM. Сборка и
  запуск Render пока **не проверены**. Если не поместится — не снимайте
  запреты безопасности; нужна отдельно оптимизированная сборка.
- Render бесплатно подходит для пробного тестирования, не для
  промышленного VALYQON. Ограничения официально описаны:
  https://render.com/docs/free
- Реальный запуск VALYQON требует HTTPS, права на обработку данных, бэкапы,
  проверенные тендеры → Worker → БД → поиск → разрешённые уведомления,
  подтверждённые платёжные права и полноценную эксплуатационную приёмку.
  Этот PR не заменяет блокирующие проверки релиза или VPS.

Никаких действий в существующем VPS, Railway, production volumes, DNS
или настоящих аккаунтах это изменение не выполняет.
