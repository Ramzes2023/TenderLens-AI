# TenderLens AI — состояние проекта

## Цель
Построить платформу анализа тендеров: Telegram, загрузка PDF, GigaChat
с возможностью подключения YandexGPT, структурированные данные, scoring,
SQL, RAG, мониторинг, FastAPI и Docker. Первоначальный сценарий — демонстрация
для портфолио с явным указанием реально реализованных возможностей.

## Текущий статус
2026-10-01: Phase 1 завершена. Создана только основа проекта для Python 3.12.
Нет исполняемого приложения, внешних запросов, подключённого бота, базы или моделей.
Библиотеки не установлены; requirements.txt не содержит зависимостей.

## Передача между сессиями
Перед изменениями: прочитать эти документы, git status и git log.
После этапа: записать выполненное, проверки, ограничения и следующий шаг.
Наличие папки или настройки не означает, что интеграция реализована.
Небольшая локальная модель — резерв для ограниченных задач, а не автономный
исполнитель всей дорожной карты.
