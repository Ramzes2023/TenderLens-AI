# TenderLens AI — состояние проекта

## Цель
Построить платформу анализа тендеров: Telegram, загрузка PDF, GigaChat
с возможностью подключения YandexGPT, структурированные данные, scoring,
SQL, RAG, мониторинг, FastAPI и Docker. Первоначальный сценарий — демонстрация
для портфолио с явным указанием реально реализованных возможностей.

## Текущий статус
2026-10-01: Phase 2 реализована: Telegram-бот на Python 3.12.14, aiogram 3.31.0,
python-dotenv 1.2.4 и aiohttp-socks 0.12.0 для необязательного прокси.
Запуск: python -m app.bot. Команды /start, /help, /status.
Реальный Telegram-токен не использовался, живой обмен сообщениями ещё не проверен.
PDF-парсинг реализован в Phase 3; LLM, SQL, scoring, RAG, API и Docker не реализованы.
