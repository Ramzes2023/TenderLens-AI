# Examples

`sample_tender.pdf` is a synthetic tender created only for TenderLens demonstration/testing. It is not an actual procurement notice and contains no real bid invitation.

Suggested demo:

1. send it to the Telegram bot;
2. review structured analysis and deterministic score;
3. resend it to demonstrate SHA-256 deduplication;
4. ask `/ask Что произойдет, если поставщик задержит доставку?` to demonstrate semantic retrieval.
